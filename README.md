# PÚBLiCA — Propuestas de sitio

Sitio estático, sin build.

- `index.html` — selector de opciones (A, B, C)
- `opcion-a.html`, `opcion-b.html`, `opcion-c.html` — cada propuesta
- `support.js` — runtime necesario para todas las páginas
- `assets/` — logo

## GitHub
1. Crear un repo nuevo y subir el contenido de esta carpeta a la raíz.

## Netlify
1. Add new site → Import from Git → elegir el repo.
2. Build command: (vacío) · Publish directory: `.`
3. Deploy.

También se puede arrastrar la carpeta directamente en app.netlify.com/drop.
